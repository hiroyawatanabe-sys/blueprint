## ■ 改訂の理由

工程07は「導線図作成」から「**導線差分設計**」へ再定義された。
型Aに焼き込まれた導線を正として書き出し、CTA設計を重ねて差分を出す工程である。

このとき、工程03の出力と型Aの間に**語彙と粒度の断絶**がある。

| 断絶 | 工程03が出しているもの | 型A／工程06・07が使う語彙 |
| :-- | :-- | :-- |
| ① 心理段階 | Stage1〜8（3D-CMF） | B列の心理段階ラベル（【見るレベル】【興味喚起／USPコンテンツ】…） |
| ② ページ種別 | 記事・コラム／比較・選び方ガイド／料金・予約 | 型Aのタブ種別（TOP／事業紹介／USP／課題解決／施工事例／お客様の声…） |
| ③ CTAの着地先 | **出力していない** | 工程06が確定ページ台帳を作る／工程07が「終端は実在ページ」を検査する |

③が過去2案件の手動補正の直接原因である（齟齬類型①：CV着地ページ欠落）。
最大CTAを「無料相談」と決めても、**その相談がどのページに着地するのか**が
工程03の出力に無いため、工程06はそのページを作らず、工程07で導線が宙に浮く。
結果、担当者が後から「/contact/ が要る」と手で足すことになっていた。

①②は、工程07が突合するたびに毎回AIが語彙を推測することになり、
案件ごとに突合結果がぶれる。

改訂は5件。**STEP1〜9の思考プロセスは変更せず、出力項目を追加する。**

## ■ 追記3｜STEP7の直後に「STEP7-2｜CTA着地先ページ要求リスト」を新設 ★最重要

**挿入位置：** 「### STEP7　ナーチャリングCTAの設計」の直後、STEP8の直前

```
### STEP7-2　CTA着地先ページ要求リストの作成【工程06への義務リスト】

ここまでに設計した**すべてのCTA**（最大CTA／入口Micro／育成Micro＝Core／ナーチャリング）
について、「押した先に何が必要か」を1件ずつ確定する。

本工程はページ構成を決める工程ではない。しかし
**CTAを設計した以上、その着地先が必要であることは本工程しか知らない。**
このリストが、工程06（ページ確定）が満たすべき義務になる。

各CTAについて、着地の形を次の3つから選ぶ。

| 着地の形 | 定義 | 工程06での扱い |
|---|---|---|
| (1) 独立ページが必要 | 専用ページに遷移する（例：問い合わせフォーム／資料DLページ） | **確定ページ台帳に必ず含める**（削除不可） |
| (2) 既存ページ内で完結 | 同一ページ内のブロック・モーダル・アンカーで完結する | 新規ページ不要。設置ブロックのみ指定 |
| (3) 外部サービスへ遷移 | LINE公式／予約システム／EC等、サイト外へ出る | ページ不要。**接続先URLの提供可否を要確認欄に立てる** |

**判定の規律：**
- 迷った場合は **(1) 独立ページが必要** に倒す（後から不要と分かる方が、無いより安全）
- (3) を選ぶ場合、その外部サービスが顧客コンテキストに**実在すること**を確認する
  （実在しないものは(1)に倒し、「外部連携が用意できない場合の代替」と注記する）
- 型Aのタブ構成に**該当ページが標準で存在するか**を併記する。
  存在しない場合は「型A外・増設要求」と明記し、工程06への増設要求として起票する

**この工程で決めないこと：** 着地ページのディレクトリ名・表示名は工程06が確定する。
本工程は「どういう性質のページが要るか」までを書く（例：「問い合わせフォーム。相談・見積の両方を受ける1枚」）。
```

## ■ 設計意図（運用者向けメモ）

| 設計要素 | 狙い |
| :-- | :-- |
| CTA着地先ページ要求リスト | 齟齬類型①（CV着地ページ欠落）の唯一の構造的解消手段。CTAを設計した工程しか着地先の必要性を知らない以上、ここで出さなければどの工程も気づけない |
| 迷ったら「独立ページが必要」に倒す | 余分なページは工程06が削除できるが、無いページは工程07まで誰も気づかない。非対称なので安全側に倒す |
| Stage ⇄ 型A心理段階の対応表を内蔵 | 工程07に推測させない。案件ごとの突合結果のぶれを消す |
| 対応表を「暫定」と明記 | Stage8に対応ラベルが無い等、型A側の未整備が実在する。AIに埋めさせず、第0層へ返す経路を作る |
| ページ種別を型Aタブ種別に統一 | 「比較・選び方ガイド」のような型Aに無い種別が主役CTAを持つと、工程06で行き場を失う |
| 03の文言を「暫定」と定義 | 設計判断D10（工程15に本文抜粋を渡す）と整合。二重確定を防ぐ |
