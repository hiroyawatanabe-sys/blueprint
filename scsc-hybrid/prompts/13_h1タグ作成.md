あなたの仕事は2つです。
(1) 全ページのh1を、3つの絶対条件に従って確定すること
(2) title / description / h1 の3点が、同じキーワードを軸に、

  条件2【1〜2回】主役KWフレーズの使用は1〜2回。
       構成語の不自然な連呼を禁止する。
  条件3【40文字以内】総文字数は40文字以内。

■ 1ページ1h1の原則
  h1は各ページに1つのみ。
  ロゴのh1化等の実装崩れを防ぐ実装注記を付す
  （TOPのみロゴ＝h1とする場合は例外規定として明記する）。

■ 役割分担の原則（3点セットの非同一）
  - h1はtitleと**完全同一にしない**（KWは共有・文言は変える）
  - h1はdescriptionの切り貼りにしない
  - h1の独自役割 ＝ **「訪問者への宣言」**
    検索結果の文脈（競合との比較）を離れ、着地した本人に向けた自然な日本語で、
    このページが何を与えるかを言い切る

  h1はファーストビューの主見出しとして機能する。
  title・descriptionで約束した内容を、h1が最初に回収すること。
  （title→クリック→h1で「約束と違う」と感じさせない）

■ 階層頂点の原則
  h1はページ内見出し階層の頂点である。
  サブKW（工程08で usage=h2見出し と指定された語）を受けるh2群が、
  h1の主題の下位展開として自然に配置できる主題設定であること。
  ※h2の具体設計は工程14。本工程は「h2が置ける主題か」の確認までとする。

■ 誠実の原則
  誇大・最上級の証拠なき使用を禁止する（統合版コンテキストの証拠範囲内）。
  記号・装飾の乱用を禁止する（h1は文章として読める形にする）。

### STEP 1｜3点セットの現状整列

ページごとに、次を1枚に整列した「設計条件シート」を作る。
- title_main（工程11）＋ differentiator_used（titleで使った差別化要素）
- description の conclusion_block（工程12）＋ weapon（descで使った武器）
- question ／ answer_core（工程12）
- FVで見せる約束（工程07）
- 主役KW（工程08・確定形）／ サブKW（usage=h2見出しのもの）

そのうえで、**h1で使う訴求の「第3の角度」を選定する**。
titleの差別化要素・descriptionの武器と同一素材の3連投を避ける。
ただし**メインの約束の一貫性は保つ** ── 「角度は変え、方向は変えない」。

### STEP 2｜ページ区分ごとのh1設計指針

a. **通常ページ（答えの宣言型）**
   主役KWを語順保持（助詞挿入は可）で含む言い切り
   例：「{市名}の内窓は、{証拠}の{屋号}にお任せください」→40字内に圧縮

b. **通常ページ（ベネフィット言い切り型）**
   訪問者が得るものを主語にする：「{KW}で__できる」構文

c. **質問型のページ**
   工程12の question をそのままh1化する「問いのh1」も選択肢とする
   （Q&A構造の頂点として。その場合 answer_core を直下のリード文で即答する方針を工程14へ申し送る）

d. **CVページ**
   行動の宣言（「{サービス}の無料見積・お申し込み」等）。
   迷いなく手続きに入れる明快さを最優先する

e. **TOPページ**
   USPのメインキャッチ（S6 copy_set）を基礎に、主戦場KWを自然統合する。
   TOPのh1＝ブランドの第一声。**ロゴ＝h1実装の可否を実装注記で明示する**

f. **可変2ページ（/company/ /company/message/）**
   工程06で確定した表示名を基礎にする
   （例：「会社情報」／個人事業主の場合「◯◯について」）

g. **対象外3ページ（/privacy-policy/ /sitemap/ /compliance/）**
   定型。C1-1-1の表記から一字も変えない：
   「プライバシーポリシー」「サイトマップ」
   「反社会的勢力に対する基本方針並びにコンプライアンス指針」
   ※文字数条件は自然充足（40字以内に収まる）

### STEP 3｜作成と機械的検査

ページごとに主案を作成し、直後に検査を実行する。

【検査1】文字数 ＝ __文字（40以内か）
【検査2】主役KW出現 ＝ __回（1〜2か）／構成語の連呼なしか
【検査3】title_main と完全同一でないか（同一なら書き直し）
【検査4】FV整合：h1はFVの約束の主見出しとして機能するか／
        title・descriptionの約束を回収しているか
【検査5】主役KWが分断されていないか（助詞の自然化を超える語順破壊がないか）
【検査6】自然文検査：声に出して読める日本語か（記号乱用・単語羅列の禁止）
【検査7】階層頂点：サブKW（usage=h2見出し）を受けるh2が下位に置ける主題か

不合格は修正→再検査。**代替案を1案**作成し、同じ検査を実施する。
構造的不成立の場合は、暫定案＋工程11または08への差戻し要求を出す。

### STEP 4｜3点対照表の作成（本工程の核心）

全ページについて、次の対照表を作成する。

| page | title（約束） | description結論（根拠） | h1（宣言） | 整合判定 |

各行について4点を確認する。
① **主役KWの共有**：3つとも同じ主役KWを軸にしているか
② **文言の非同一**：3つが互いにコピペになっていないか
③ **約束→根拠→宣言の一貫性**：3つが1つの訴求として流れるか
④ **矛盾ゼロ**：titleの約束をh1が裏切っていないか

**矛盾を発見した場合、隠さず記録する。**
h1側で解決できるものは修正し、title・description側の修正が必要なものは
差戻し要求として出力する。

### STEP 5｜横断検査

a. 全ページ相互のh1重複ゼロ
b. 書き分け宣言（工程08）のあるペアについて、h1の対照で意図の違いが読めるか
c. 表記統一（工程11の表記規則表との全数照合）

### STEP 6｜工程14への申し送り

h1を確定した各ページについて、次を工程14（見出し＋文章作成）へ渡す。
- サブKW（usage=h2見出し）の一覧 ── h2の材料
- 「問いのh1」を採用したページ ── 直下リードでanswer_coreを即答する方針
- description記載の数字・約束 ── 本文で必ず回収・詳述すべき項目
- title の differentiator_used ── 本文冒頭で即座に回収すべき要素

※**h2骨子そのものは作らない。**材料と方針の受け渡しに留める。

## ■ 設計意図（運用者向けメモ）

| 設計要素 | 狙い |
| :-- | :-- |
| 3点対照表を本工程に置く | title・description・h1を別工程で作る以上、どこかで並べて見ないと重複・矛盾が残る。最後に作るh1工程が最適地点 |
| h2骨子を出さない | 見出しと文章を同一工程（工程14）に統合した決定に合わせる。h1工程は材料と方針だけ渡す |
| 「第3の角度」の選定 | 同じ素材を3連投すると、検索結果と着地後で同じことを3回言うことになる |
| 「角度は変え、方向は変えない」 | 角度を変えすぎると約束の一貫性が壊れる。振れ幅の上限を明示 |
| 助詞挿入による自然化を許容 | h1はページ内文言。title（検索結果の文脈）とは求められる自然さが違う |
| 矛盾の隠蔽を禁止 | 3点対照表は品質の証明であり、矛盾ゼロを演出する場ではない |
